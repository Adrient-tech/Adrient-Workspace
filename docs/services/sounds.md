# Sounds

Ringtones, meeting chimes and notification tones. All tones are original,
generated by `scripts/gen-sounds.mjs` (additive synthesis with envelopes,
harmonics and a light reverb, encoded to mp3 with ffmpeg). No third-party audio is used.

## Where things are

| What | Where |
| --- | --- |
| Tone files | `web/app/public/sounds/<set>/<id>.mp3` (sets: `classic`, `soft`, `bright`) |
| Generator | `scripts/gen-sounds.mjs` (`node scripts/gen-sounds.mjs`, needs ffmpeg; `--wav` writes wav without ffmpeg) |
| Player | `web/app/src/lib/sounds/` (`SoundManager`, catalogue, preferences) |
| Settings screen | Settings > Sounds (`/settings/sounds`) |

## Sound ids

Calls: `ringtone` (loops), `ringback` (loops). Meetings: `join`, `leave`, `hand`, `mute`, `unmute`,
`share`, `rec_start`, `rec_stop`, `meeting_ended`. Chat: `message`, `dm`, `mention`. Others: `mail`,
`calendar`, `task`, `approval`, `alert`, `success`, `error`.

## Where each sound plays

- Incoming call dialog: `ringtone` until answered, declined, cancelled or 45 s. Outgoing call: `ringback` until the other side answers, declines or you hang up.
- Meet: `join` / `leave` (participants), `hand`, `mute` / `unmute` (own microphone, also from the call bar), `share`, `rec_start` / `rec_stop`, `meeting_ended` (host ended it for everyone).
- Chat: `dm`, `mention` or `message` for a message in a background channel; `task` for a message reminder.
- Mail: `mail` when the inbox unread count rises while Mail is open (checked once a minute).
- Notification centre: every live notification plays the tone of its kind (`calendar_reminder` is `calendar`, `task_assigned` is `task`, kinds containing `approv` are `approval`, `mention` kinds `mention`, `mail` is `mail`, `alert` / `system` kinds `alert`, anything else `message`).
- Settings: `success` / `error` on save.

## Replacing a tone

Drop a file with the same name into `web/app/public/sounds/<set>/` (for example `classic/ringtone.mp3`)
and rebuild the web app, or replace it in the deployed `sounds/` folder. Rules:

- Keep the file name and the `.mp3` extension (other formats need the extension changed in `lib/sounds/catalog.ts`, `soundUrl`).
- Keep one-shots short (under 2 s) and peak-normalised below 0 dBFS. `ringtone` and `ringback` loop, so end them with a short silence.
- Keep all three sets complete; a missing file is silent and logged as a 404.

To change the built-in melodies or timbres, edit `SOUNDS` and `SETS` in `scripts/gen-sounds.mjs` and run it again.

## Behaviour

- Browsers refuse audio before a user gesture. The player unlocks on the first click or key press; a ringtone that was refused starts at that moment.
- Do Not Disturb (manual switch, or scheduled quiet hours) silences everything, ringtones included. Test buttons in Settings > Sounds always play.
- With "Follow my system's reduced-motion setting" on (default), notification tones stay quiet when the OS asks for reduced motion. Calls still ring.
- A looping sound stops by itself after 60 s.
- Preferences (volume, tone set, per-area switches, quiet hours, desktop alerts) are saved in the account's preferences (`extra.sounds`) with a local copy for a fast start.
- Desktop notifications are opt-in on the Sounds screen; the browser asks for permission when you turn them on.

## Events for tests

The player dispatches `adrient:sound` on `window` with `detail: { id, kind, reason? }` where kind is
`play`, `loop`, `stop`, `blocked` (autoplay refused) or `skipped` (reason: `category`, `dnd`, `system`, `volume`).
