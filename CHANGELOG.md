# Changelog

All notable changes to Adrient Workspace.

## 1.0.0

First public release of Adrient Workspace.

- **Files and documents:** Drive, Docs, Sheets, Slides, PDF, Forms, Keep, Whiteboard, Photos, Books.
- **Communication:** Mail, Chat, Meet, Calendar with booking pages, Contacts, Telephony.
- **People:** HR (employees, leave, attendance, payroll), Talent (hiring, onboarding, performance, learning), Shifts, Time tracking.
- **Money and operations:** Accounting, Invoicing, Inventory and purchasing, POS, Field service, Fleet.
- **Customers and work:** CRM, Projects, Tasks, Tickets, Contracts, Signatures, Legal, Cap table.
- **Knowledge:** Records, Wiki, Sites.
- **Administration:** Admin console, user types and guests, per-app controls, SCIM, access reviews, audit log.
- **AI assistant** in every app, with a model of your choice, admin controls and an audit log.
- **Office-style ribbons** in Sheets, Docs and Slides.
- **Migration:** Cloud Import from Google Workspace, Microsoft 365, Zoho, Nextcloud, ownCloud and any IMAP, CalDAV or WebDAV server.
- **Operations:** the `adrient-admin` command (migrate, backup, restore, export, seed-demo), a one-command server installer, a Helm chart and a local dev stack.
